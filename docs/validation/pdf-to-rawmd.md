# pdf-to-rawmd 초기 이전 검증

검증일: 2026-11-12. 별도 저장소의 첫 이전이며 버전 번호와 릴리스 태그는 지정하지 않았다.

## 변경 범위

- 영구 source-map, 원본 객체 전체 inventory, 숨은 `raw:block` ID, chunk 연결 JSON과 stale 연결 검사를 제거했다.
- 원문·표·수식·강조·Figure 설명·실제 PNG·원본 페이지 번호·독립 전수 검수는 유지했다.
- native 초안을 코드로 저장하고 작업자는 필요한 부분을 수정한다. 초안과 packet 중 하나를 주 입력으로 선택해 중복 읽기를 줄인다.
- 렌더를 재사용하고 필요한 영역만 확대한다. 독립 검토는 문제 위치를 보고하며 수정 범위만 재검토한다.
- 자동 초안과 그림 후보는 `UNREVIEWED`다. 구조 검사 성공을 내용 검수 완료로 취급하지 않는다.

## 정적 지침 토큰

`tiktoken`의 `o200k_base`로 각 UTF-8 지침 파일을 따로 인코딩한 뒤 합산했다. 비교 대상은 작업 시작 시의 로컬 원본 Skill과 이 저장소다. 이는 모델의 실제 실행 사용량, 이미지 토큰, 추론 토큰, 캐시 사용량을 측정한 결과가 아니다.

| 읽기 경로 | 이전 | 경량화본 | 감소 |
|---|---:|---:|---:|
| SKILL.md | 2,633 | 1,774 | 32.6% |
| PDF: SKILL + RAW 형식 + 이전 source-map 지침 | 10,029 | 2,980 | 70.3% |
| PPTX: PDF 경로 + PPTX 지침 | 11,920 | 3,553 | 70.2% |

경량화본의 PDF/PPTX 경로에는 source-map 지침이 없다. 원본 자료가 달라질 때의 전체 실행 토큰 절감률은 아직 측정하지 않았다.

## 패키지와 설치본 보존

- 루트 `plugin.json`: 공식 portable plugin JSON Schema 검증 통과. 이 스키마는 버전을 필수로 요구하지 않는다.
- Claude plugin/marketplace 검증: 오류 0, 버전 미지정 경고만 존재한다. `--strict`는 이 의도적인 경고 때문에 실패하므로 strict 통과로 보고하지 않는다.
- skill-creator `quick_validate.py`: 통과.
- 기존 로컬 `pdf-to-rawmd` 파일 11개: 작업 전후 SHA-256 차이 0개. 기존 저장소의 별도 변경은 보존했다.
- 로컬 Skill 또는 설치된 플러그인에 배포하지 않았다.

## 독립 코드 리뷰

다중 Figure 번호와 대괄호 캡션, Markdown literal, 파일 헤더 escape, 기본 packet에서 발표자 노트 제외를 보정했다. 수정 후 독립 재검토에서 추가 차단 finding은 없었다. 기존 파일 덮어쓰기와 임베드 경로 이탈을 거부하는 동작도 확인했다.
