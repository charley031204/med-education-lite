# 친구에게 전달할 학습 파이프라인

이 플러그인은 사용자가 정한 수업 전·후 절차를 개별 Skill로 제공한다. 단계마다 파일을 인계하며 전체 과목을 한 대화에 계속 누적하지 않는다. 실제 Skill 이름은 소문자이며, `/`는 Claude Code의 호출 표기다.

## 준비

과목 폴더에 다음 영역을 준비한다. 기존 폴더가 있으면 이름과 번호를 그대로 사용한다.

```text
과목명/
├── 01. RAW/          # 강의록별 폴더 안에 RAW MD + 동봉 이미지
├── 02. 녹음 정제/
├── 03. 최종정리본/
└── 04. 소스/         # 원본 강의록·Whisper TXT·전체 기출 MD와 이미지
```

전체 기출의 원문 MD·실제 이미지와 시간표는 사전에 준비한다. 이 패키지는 Whisper 전사 프로그램이나 Notion 시간표 생성기를 포함하지 않는다. 이미지가 있는 문서는 MD 파일만 옮기지 말고 참조 이미지를 함께 전달한다.

## 수업 전 — 서로 다른 새 채팅

1. `/pdf-to-rawmd`: 강의 PDF/PPTX와 출력 상위 폴더를 지정한다. 강의록별 새 폴더에 원문 RAW MD와 전용 `동봉 이미지/`를 만든다.
2. **새 채팅**에서 `/yama-chapter-word`: 강의록/RAW MD와 전체 기출을 지정한다. 해당 강의 범위의 문항을 원문·실제 이미지·출제 이력과 함께 문제 전용 Word로 만든다.

두 단계는 같은 대화에서 이어서 실행하지 않는다. 첫 단계의 최종 파일 경로와 남은 판독 문제만 인계한다. 원문 전체를 채팅에 다시 붙이지 않는다.

## 수업 후

1. Whisper 프로그램으로 녹음을 TXT로 전사한다.
2. `/med-transcript-polish`: TXT와 대응 강의록/RAW MD를 지정한다. 이 파이프라인에서는 **페이지 태깅 ON**을 기본으로 사용한다. 판독·페이지 대응이 불확실하면 표시를 남긴다.
3. `/transcript-pdf-study`: 녹음정제 PART 2, 강의록, 관련 기출을 지정한다. 읽기 좋은 정리본과 Keyword·핵심 요약을 **PDF와 편집 가능한 Word**로 만든다. HTML은 납품하지 않는다. 기출 대응 내용은 매우 연한 노란색, 교수의 실제 시험 언급은 매우 연한 초록색으로 표시한다. 강의록 이미지가 필요하면 포함하도록 요청한다.
4. `/yama-question-answer`: 한 문항 또는 해당 문항에 관한 질문을 한다. 강의록과 Script에서 관련 내용을 먼저 찾아 답하며, 추론 답안·공식 답안·자료 간 충돌을 구분한다.

여러 문항의 Word를 Obsidian 해설집으로 옮기는 경우에는 `/yama-word-obsidian`을 별도로 쓴다. 한 문항 질문에 전체 해설집을 생성하지 않는다.

## Google Drive 목적지

친구 환경에서 업로드할 폴더를 한 번 지정한다. 현재 요청 또는 사용자가 설정·기억시킨 정확한 폴더가 있으면 `/transcript-pdf-study`가 PDF·Word 생성을 마친 뒤 그곳에 자동 업로드하고 결과 링크를 확인한다. 목적지가 없거나 접근할 수 없으면 로컬 결과를 보존하고 필요한 경로/접근만 요청한다. 유사한 이름의 다른 폴더를 임의 선택하지 않는다. 이 저장소를 설치하는 것만으로 개인 메모리나 Drive 설정을 변경하지 않는다.

## 사용자 지정 모델·추론 프리셋

아래는 파이프라인 작성자가 적은 선호값이다. 실제 모델 제공 여부·API 식별자는 확인한 값이 아니므로 코드에 고정하지 않는다. 호스트에 해당 선택지가 있으면 적용하고, 없으면 사용 가능한 대안을 사용자와 정한다.

## 토큰을 줄이는 처리 원칙

원문은 로컬 파일에 두고 페이지·문항·전사 구간을 지정해 읽는다. 코드가 원문을 복사·색인·조립·렌더하고, 모델은 범위 판단·불확실한 표현·내용 설명에 집중한다. 단계 간에는 경로·범위·미해결 사항만 넘긴다. 수정 시 관련 구간만 다시 검토한다. 기출의 선지·그림이나 교수의 시험 언급을 줄여 토큰을 절약하지 않는다.
