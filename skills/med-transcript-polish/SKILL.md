# 의대 강의 녹음 정제

입력은 Whisper TXT 또는 붙여넣은 전사문이다. 교안 RAW MD, 과목명, 강의명, 날짜, 교수명, 주제 순서를 받은 경우 활용한다. 빠진 정보는 파일명·교안·발화에서 확인하고, 근거가 없으면 생략하거나 미확인으로 남긴다. 교안이 있으면 페이지 태깅을 기본으로 적용한다. 사용자가 끄라고 하면 용어 대조에 교안을 활용한다.

## 처리 순서

1. [도구 사용법](references/workflow.md)에 따라 새 작업 폴더에 TXT를 분할한다. 원본은 유지한다. 타임스탬프와 청크 경계는 작업용 위치 정보다.
2. 짧은 입력은 현재 작업자가 처리한다. 긴 입력은 호스트가 지원하면 범위를 제한한 새 작업자에게 청크와 양쪽의 짧은 문맥을 준다. 교안은 제목·정식 용어·수치·도표 라벨로 검색하고 필요한 페이지만 확인한다. 검색 단서가 부족하면 해당 쟁점에 한해 범위를 넓힌다.
3. 작업자는 배정된 발화를 교정하고 교정문을 원본과 대조한다. 청크마다 교정 파일과 PART 2에 쓸 짧은 주제 메모를 저장한다. 이웃 청크에서 문장이 이어지면 두 작업자의 파일 경계만 대조해 연결을 확정한다. 페이지 태그는 교정문을 확정한 후 근거가 있는 기존 줄 앞에 추가한다.
4. PART 2는 확인된 메모를 주제별로 묶어 한 번 작성한다. 서로 어긋나는 내용, 시험 언급, 문맥이 부족한 부분은 해당 교정문과 원문을 다시 확인한다. 긴 입력에서 총괄 작업자는 검사 결과와 경계·미해결 목록을 받는다.
5. 도구로 원문 분할의 재조합, 청크 순서와 누락, 페이지 번호, 태그 제거 전후 본문 동일성을 검사하고 Markdown을 조립한다. 의미 검토는 청크별 원문 대조에서 수행한다. 최종 응답에 결과 경로와 해소되지 않은 용어·페이지 상태를 남긴다.

## PART 1 — 교정 스크립트 (순수 정제)

- 발화 순서, 구어체, 수치·단위, 부정·조건·예외, 불확실성, 예시와 강조를 유지한다. 명백한 인식 오류, 한글로 음역된 의학 용어, 문장부호를 교정한다. 의미와 강조를 보존할 수 있을 때만 즉각 반복과 필러를 줄인다.
- 교안에 나온 정식 용어와 주변 발화가 일치하면 용어를 복원한다. 후보가 유력하나 불확실하면 원문 음역을 함께 남긴다. 예시 표기는 `coronoid[?/크로노이드] process`다. 후보를 특정할 수 없으면 원문과 `[추론불가]`를 남긴다.
- 실제 주제 변화에서 단락을 나눈다. 문장 중간에 타임스탬프가 있으면 문장을 이어 쓴다. 요약·재배치·섹션 헤더·교안 보충은 PART 2에서 필요한 경우 처리한다.
- 페이지의 실제 제목, 고유 개념, 수치, 도표 라벨과 발화 순서를 대조한다. 후보 검색 순위와 쪽수 순서는 단서다. 확인된 전환은 `[Page N]`, 특정 페이지의 후보 근거가 있으나 경계가 흐리면 `[Page N?]`를 쓴다. 여러 쪽이 비슷해 구별할 근거가 없으면 본문을 유지하고 검토 파일에 미해결 사유를 남긴다.
- 같은 페이지 태그는 한 번만 쓴다. 앞 페이지로 돌아간 발화는 원래 위치에 두고 반복 태그가 필요한 경우 검토 사항으로 남긴다. 페이지 번호가 확인된 생략에만 `(이 페이지는 교수님이 넘어가심)`을 쓴다.

## PART 2 — 강의 정리본 (녹음본 요약)

확인된 발화를 학습 순서로 재구성한다. 교수, 강의 범위, 강의 흐름, 핵심 키워드, 시험 포인트를 근거에 따라 넣고 주제별 제목·표·목록을 활용한다. 실제 시험 발언은 `> 💡 시험 포인트: …`로 표시하고 인용을 확인할 수 있게 보존한다. 교안 보충을 넣는 경우 출처를 밝혀 발화와 구별한다. 페이지 태그는 PART 1에만 넣는다.

결과는 UTF-8 Markdown 한 파일이다. 문서 제목과 PART 1·PART 2를 구분선으로 나눈다. PART 2는 표준 헤더 다음부터 파일 끝까지이며 내부 구분선·하위 제목을 사용할 수 있다.
