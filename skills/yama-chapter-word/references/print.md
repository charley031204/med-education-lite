# 인쇄와 검수

- A4 세로, 2.2cm 여백, 바탕체 10.5pt, 하단 중앙 쪽번호를 유지한다. 문두에 `[25,23]`, 아래 줄에 `※ 출제 이력: 25년 88번 · 23년 76번`을 둔다. 차수와 번호가 원문에 있으면 보존한다. 같은 문항을 병합했으면 공시한다. 타 교수 분리는 문항별 출제자 근거나 제공된 연도별 교수 매핑을 따른다.
- 공통지문과 가/나/다·ㄱ/ㄴ/ㄷ 보기 박스를 발문에 연결한다. 문두와 선지의 명백한 줄 경계만 복원한다. 불확실한 조각과 원문 누락은 추정으로 채우지 않는다.
- 인접한 그림과 대응 라벨을 1행 표로 시도한다. 두 열 가용폭은 각각 8.1cm다. 본문·조건·선지를 가로 배치를 위해 이동하지 않는다. 세로 합성 그림은 실제 패널 사이 흰 띠가 있는 경우에만 분할하고 원본은 유지한다. 이미지 폭은 8cm 이상이어야 한다.
- 공통사진 문서는 원문별 문항·번호와 원본 이미지 연결을 보존한다. 공유 머리와 첫 문항을 함께 실측한다. 이후 페이지에 이어질 경우 참조 문구를 사용한다. [사진 검토 절차](SHARED_PHOTOS.md)와 Word의 embedded media 검사를 따른다.

## 결과 확인

1. `source_content_ok`, `source_ids_preserved`, 원문 선택 수, 표시 문항 수, 문항별 출제 이력, `missing_images`와 공통사진 결과를 확인한다. 선택 근거·제외·미확정 목록은 사람이 검토한다.
2. 실제 DOCX와 연결된 `*.layout-qc.json`에서 `word.status: OK`, `word.spans_pages: []`, 검사 결과 및 최종 SHA-256을 확인한다. 문항 높이 추정과 실제 Word 조판 결과를 구별한다.
3. `--preview-pdf`로 Word에서 내보낸 검수본을 페이지별로 본다. 문두·선지·이력의 끊김, 인쇄 영역 잘림, 실제 그림·캡션, 보기·공통지문의 배치를 전수 확인한다. 사진과 문제의 대응 및 두 그림을 같은 행에 놓았을 때의 판독 가능성도 확인한다.
4. 결과가 `CHECK`이거나 시각 검수에서 결함이 있으면 해당 항목을 수정하고 최신 DOCX를 다시 검수한다. 실측이나 시각 검수가 불가능하면 결과 보고에 남긴다.
