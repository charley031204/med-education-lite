# 야마 Word

해당 강의의 실제 기출만 수록한다. 원문 발문·선지·조건·미복기·복기자 주석·연도와 번호·그림과 캡션을 유지한다. 페이지는 A4 세로 숙방·해환 양식으로 조판한다. 정답, 해설, 보충 블록은 사용자가 요청했을 때만 붙인다.

## 1. 후보 찾기

1. 전연도 통합 RAW MD, 동봉 이미지, 강의 RAW MD와 시간표를 확인한다. 같은 폴더의 `*_questions.csv`를 먼저 찾고, 따로 지정된 CSV는 `--csv`로 전달한다. RAW에는 원문 문항이 있고, CSV의 `topic_candidates`·`prof_past`는 후보 탐색에 쓴다. 챕터 제목의 과거 교수명은 개별 문항의 출제 교수 근거로 쓰지 않는다.
2. [실행 예시](references/workflow.md)에 따라 문항은행을 작업 폴더에 한 번 색인한다. Index에는 원문이 있으므로 에이전트 컨텍스트나 공유 저장소에 넣지 않는다. 에이전트는 stdout의 챕터 목록·문항 수·CSV 연결 상태를 확인한다.
3. 대상 주제, 시간표에 확인된 별칭, 실제 교안의 구별력 있는 용어로 후보 패킷을 만든다. 후보는 원래 챕터·CSV 후보·교안 용어·확인한 문항 번호 구간을 합친다. 필요한 경우 서술형 단서도 검색한다. 대상 챕터가 없거나 임의 분류 마커가 없을 때도 교안 용어를 검색한다. 교안이 겹치거나 CSV가 없으면 강의 범위와 커버리지 한계를 기록한다.

## 2. 수록 범위 확정

- 후보 패킷 단위로 원문과 관련 교안 페이지만 비교한다. 대상 챕터 안에서 범위 밖인 문항과 다른 챕터에서 빠진 문항을 함께 확인한다. 선지에서 용어가 발견되면 검토 대상으로 삼고, 질문이 묻는 개념·조건과 강의 근거로 소속을 결정한다.
- 분량이 크면 새 작업자 컨텍스트에 후보 ID·관련 교안 페이지·판정 기준만 맡긴다. 각 작업자는 ID별 수록·제외·미확정과 근거 페이지를 반환한다. 메인 에이전트는 후보 수·미확정·충돌·중복과 최종 ID 집합을 확인한다. 명확한 경우 별도 승인 없이 진행하고, 범위가 달라지는 미확정만 사용자에게 확인한다.
- 선택 파일에 ID와 주제·담당 교수만 적는다. 빌더가 색인에서 문항을 복사한다. 순서를 바꾸려면 ID 순서나 근거가 확인된 페이지 매핑을 사용한다. 원본 파일과 상류 CSV에는 쓰지 않는다. 긴 문장의 줄바꿈을 복원할 때는 동일한 문항 안의 글자·순서·선지 소속을 대조한다.

## 3. Word 생성과 검수

- Word 빌더에 원본·색인·선택 파일을 전달한다. 본문 전체 보고서는 `--report`로 로컬 파일에 저장한다. 같은 문두에 선지나 조건이 다르면 별도 문항으로 둔다. 자동 병합 시 원문 이력마다 두 자리 연도와 원본 번호를 표시하고 병합 사실을 밝힌다. 연도나 번호가 없으면 미상 표기를 유지한다.
- 사진이 있으면 [공통사진 검토](references/SHARED_PHOTOS.md)를 따라 전체 사진을 검토한다. 같은 사진을 공유하는 문항도 원문별 소문항과 이력을 유지한다. 각 소문항의 전용 사진은 그 문항에 남긴다.
- 독립 검토자에게 선택한 원문과 실제 Word를 범위별로 맡긴다. 문항 전체의 발문·선지·이력·이미지를 전수 대조하고, 경계 후보의 제외 근거와 미확정을 확인한다.
- [인쇄·검수 규격](references/print.md)으로 원문 수·표시 수·이미지 수와 연결·내용 및 Word 페이지를 확인한다. Word 실측과 실제 PDF 페이지 확인을 둘 다 수행한다. Windows Word와 `pywin32`가 없거나 실측이 실패하면 미검증 항목을 보고한다.
- 최종 보고에는 DOCX 경로, 선택한 원문 수·표시 문항 수, 누락·미확정·원천 커버리지, 실제 페이지 검수 상태를 적는다. 후속 학습 정리와 단일 문항 해설에는 Word 경로와 확인된 주제·범위를 전달한다.
