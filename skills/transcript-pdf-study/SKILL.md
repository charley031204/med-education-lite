# 녹음정제본 학습 PDF와 Word

PT2의 학습 내용을 보존하면서 설명 순서와 문장 흐름, 표와 줄바꿈을 다듬는다. 입력 하나마다 PDF와 편집 가능한 DOCX를 함께 만든다. 의학적 사실·조건·수치·불확실성을 임의로 교정하거나 삭제하지 않는다. 기존 `transcript-study-pdf`의 목적을 이어받되 HTML을 산출물에서 제외한다.

## 입력과 읽기 범위

- 녹음정제 Markdown, 대응 강의 RAW Markdown 또는 읽을 수 있는 강의 추출본을 받는다. 기출 은행/문항집 경로도 찾는다. 없는 자료를 읽었다고 기록하지 않는다.
- `scripts/prepare_study.py input.md --out <작업폴더>/pt2.md`로 PT2 경계를 검사하고 한 번 추출한다. `PART 2`, `PT.2`, `2부` 헤딩을 지원한다. 내부 `---`, 소제목, 표는 EOF까지 유지한다. 경계가 여러 개면 확인한다. 녹음정제 스킬의 PT2에는 페이지 태그가 없어도 정상이다.
- PT2 전체는 한 번 읽는다. 강의는 목차와 PT2의 개념어로 검색한 대응 페이지를 읽는다. 기출은 해당 강의의 문항 줄기·선지·그림 설명을 검색해 전체 문항 문맥을 확인한다. Script PART 1은 시험 발언과 불확실한 문구를 확인할 때만 주변 발언을 조회한다.
- 검색 결과 한 줄만 보고 색을 정하지 않는다. 대응 범위가 불명확하면 조회 범위를 넓힌다. 누락 검토에는 PT2 전체와 표의 모든 셀을 사용한다. 토큰 절약을 이유로 내용을 생략하지 않는다.

## 내용 편집과 근거

1. 학습 순서에 맞춰 PT2를 개념·기전·비교·적용 등 필요한 단위로 재배열한다. 강의의 관련 설명을 확인하며 문장과 연결을 다듬는다. 표에만 있는 사실, 영어 병기, 수치·용량, 범위 제한, 상충 설명을 보존한다. 무관한 새 지식을 추가하지 않는다.
2. 첫 부분에 핵심 키워드와 핵심 정리를 둔다. 각각 PT2 또는 대응 강의의 실제 근거 구절을 연결한다. 강의에 없는 시험 예상이나 중요도를 생성하지 않는다. 단순 복사나 과도한 압축 대신 학습하기 쉬운 설명으로 만든다.
3. 기출 문항이 실제로 묻는 내용과 대응하는 **최소 의미 구간만** 매우 연한 노랑 `FFF8D9`으로 표시한다. 단어가 겹친다는 이유만으로 문단 전체를 칠하지 않는다. 문항의 정답을 임의로 확정하지 않는다.
4. 교수의 PART 1 발언에 명시적인 시험/출제 언급이 있을 때만 매우 연한 초록 `E7F3E7`으로 표시한다. 일반 강조, 중요하다는 말, 에이전트의 출제 예측은 초록 근거가 아니다. 부정·예외·이번 시험 제외를 포함해 발언 범위를 읽는다. 제외 발언은 시험 포함으로 표시하지 않는다.
5. 두 근거가 겹치면 본문 노랑과 인접 초록 `[교수 시험 언급]` 표지를 함께 유지한다. `[기출]` 표지도 남겨 색만으로 구별하지 않는다. 작업 JSON의 각 span에 실제 인용, 출처, 위치, 대응 이유를 직접 둔다. 별도 source-map·영구 원장·중앙 실행 레지스트리는 만들지 않는다.
6. 사용자가 이미지를 요청하면 해당 강의의 실제 그림을 열어 확인하고 필요한 본문에 삽입한다. 원래 라벨·캡션과 의미를 보존한다. 이미지 요청이 없으면 자동 추가하지 않는다. 긴 표는 2–4열 비교표나 여러 소절로 나누되 셀 내용을 생략하지 않는다.

## 한 번 편집하고 두 형식에 재사용

에이전트가 검토한 내용을 [구조화 입력 규격](references/renderer.md)의 `study.json`으로 한 번 작성한다. 이것은 제작 입력이며 납품용 문서가 아니다. 강의와 PT2를 다시 붙여 넣어 DOCX와 PDF 내용을 따로 생성하지 않는다. 빌더는 편집 가능한 문단·표·이미지를 DOCX로 만들고 **그 DOCX를 PDF로 변환**한다. PDF→Word 역변환이나 페이지 스크린샷 Word는 사용하지 않는다.

```powershell
python scripts/render_study.py "<작업폴더>/study.json" --output "<출력폴더>/<강의명>_PT2_정리본" --work-dir "<작업폴더>/render" --converter word
```

Windows Word가 없으면 `--converter libreoffice --soffice <실행파일>`을 사용한다. Codex에서는 먼저 `load_workspace_dependencies`로 번들 런타임과 변환기를 찾는다. 부족한 의존성은 실제 환경과 설치 지침을 확인한다. 사용자 앱을 전경으로 열거나 포커스·마우스를 조작하지 않는다. Word 경로는 새 비가시 인스턴스만 사용하며 기존 프로세스를 닫지 않는다. 변환 실패 시 DOCX를 보존하고 PDF 미생성을 명시한다. HTML로 대신 완료하지 않는다.

출력 경로는 사용자 지정이 우선이다. 과목의 녹음정제 폴더 입력이면 대응 최종정리본 폴더를 기본으로 한다. 입력 원본은 변경하지 않는다. 기존 산출물 수정 요청이 있을 때만 `--overwrite`를 사용한다.

## 결과 검수

- 본문 A4 세로, 약 10.6pt와 충분한 줄간격을 기준으로 한다. 기본 글꼴은 Windows에서 검증한 `Malgun Gothic`이다. 기존 RIDIBatang-9 OTF는 이 Word 환경에서 대체되어 기본값으로 사용하지 않는다. `font_family`로 변환 환경에 설치된 한국어 글꼴을 지정할 수 있으며 실제 PDF 폰트를 확인해야 한다. 편집하는 컴퓨터에도 같은 글꼴이 필요하다. 동봉 RIDIBatang-9와 라이선스는 선택 사용용으로 보존한다. 제목, 핵심 정리, 표, 그림 캡션을 화면과 인쇄에서 읽을 수 있게 배치한다.
- 최종 PDF의 **전 페이지 PNG**를 확인한다. 한글/영문 줄바꿈, 긴 단어·괄호, 표 셀·행, 그림 라벨, 제목 고립, 하단 잔여 줄, 잘림·겹침·빈 페이지를 확인한다. 문제를 고치면 새 DOCX→PDF→PNG로 다시 확인한다.
- `qc.json`은 폰트와 페이지 경계를 기계 검사하며 내용·시각 검수를 자동 승인하지 않는다. 완료 기록에 PDF/DOCX SHA-256, 실제 확인한 페이지, 의미 검토 결과를 남긴다. PT2 전체의 사실·조건·표 셀과 최종 본문을 대조한다. 키워드·요약의 근거와 모든 색 표시를 별도로 확인한다.
- 원본 PDF는 읽기 전용이다. 작업 JSON의 `originals`에 사용한 원본 PDF/PPTX 등을 선언한다. 출력 경로가 입력·이미지·원본과 같거나 작업 폴더가 입력을 포함하면 빌더가 거부한다. `--overwrite`도 이 보호를 우회하지 않는다.
- 수정은 JSON의 해당 부분만 바꾸고 빌더를 다시 실행한다. 읽을 때도 변경된 근거 구간만 재조회한다. 최종 전 페이지 시각 검수와 의미 검수 범위는 줄이지 않는다. 실제 사용량 측정 없이 토큰 절감률을 말하지 않는다.

## 지정 Google Drive 폴더로 자동 업로드

완성 후 사용자가 사전에 지정한 설정/현재 요청/명시적으로 기억시킨 목적지에서 **정확한 폴더 ID 또는 링크**를 확인한다. 현재 환경의 Drive connector와 관련 스킬을 읽고 PDF와 DOCX를 모두 그 폴더에 업로드한다. 목적지가 이미 명시되어 있으면 업로드를 다시 허락받지 않는다.

목적지가 없거나 서로 충돌하면 폴더 링크를 한 번 묻고 로컬 산출물과 검수를 먼저 완료한다. 답을 받기 전에 임의 폴더를 만들거나 다른 폴더로 올리지 않는다. 폴더를 기억시키라는 요청 없이 메모리에 쓰지 않는다. 연결 도구가 없으면 로컬 결과와 업로드 미완료 상태를 보고한다.

재시도 전 지정 폴더의 같은 이름·크기·지원되는 체크섬을 조회해 이미 성공한 업로드를 재사용한다. 확인되지 않은 파일을 같은 것으로 간주하지 않는다. 업로드 후 각 파일 ID/URL, 부모 폴더, 이름·크기·지원되는 체크섬을 다시 읽어 검증한다. 응답을 얻지 못했으면 성공을 주장하지 않는다. 빌더의 `drive_upload: not_attempted`는 API 업로드 상태가 아니며 작업 기록에서 실제 결과를 별도로 남긴다.

최종 답변에는 PDF·DOCX 링크, 페이지 수, 수행한 검수와 남은 한계, 실제 업로드한 경우 두 Drive 링크를 제공한다. 임시 파일을 자동 삭제하지 않는다. 정리가 필요하면 이번 작업 소유 임시 파일만 대상으로 하는 사용자 실행 스크립트를 제공하고 원본·산출물·참조 그림·QA 근거는 보존한다.
