# 기출 답안 원칙

- 같은 문항인지 연도·회차·번호·문두와 그림으로 확인한다. 번호가 중복되면 필요한 식별 정보를 요청한다. 복기에 빠진 문구, 선지 또는 정답을 채워 넣지 않는다.
- 강의록과 Script를 먼저 확인한다. Script PART 1에서 교수가 직접 답을 정리하거나 수정한 구간을 확인한다. PART 2는 요약 자료다. 답안을 뒷받침하는 원문과 위치를 필요한 만큼만 인용한다. 페이지 경계가 불확실하면 `p.N?`를 유지한다.
- 문항에 정확히 대응하는 공식 답안, 교수의 직접 답변, 자료 기반 풀이, 정답 불확실을 구분한다. 편집자 팁과 복기 정답은 확인 단서로 사용할 수 있다. 공식 답안과 교수 발언을 모두 확인할 수 있고 서로 다르면 두 출처와 차이를 밝힌다. 강의록과 Script가 다르면 두 근거를 남기고, 범위가 같은 문항에 대한 교수의 직접 최종 발언이 확인되면 그 판단을 따른다. 차이를 해소할 수 없으면 정답 불확실로 표시한다. 사용자가 지정한 출처 기준이 있으면 적용한다.
- 객관식은 문두가 요구하는 판단 방향을 먼저 확인한다. 각 선지의 성질이 그 조건에 맞는지 설명한다. 오답은 어떤 부분이 틀렸는지와 해당 개념이 실제로 적용되는 조건을 짚는다. 복수정답·부정형·매칭형의 판정 기준과 답을 정확히 대응시킨다. 진술 세트는 각 진술을 판단하고 선택지 조합으로 연결한다.
- 주관식은 정의나 결론을 먼저 쓰고 채점어와 조건을 제시한다. 비교축은 표로, 병렬 항목은 ①②③으로, 기전은 `→`로 정리한다. 핵심 용어·수치만 굵게 표시한다. 선지별 풀이 뒤에 문제를 푸는 데 필요한 공통 기준이나 기전을 짧게 정리한다.
- 사진 문항은 실제 그림과 캡션을 확인하고 관찰과 해석을 구분한다. 사진이 없거나 읽기 어려운 부분은 한계로 적는다. 문항 번호나 캡션만 보고 판독을 단정하지 않는다.
- 필요한 결론이나 선지 설명을 강의록과 Script에서 모두 확인할 수 없으면 누락된 주장만 따로 밝힌다. 표준교과서를 실제 확인해 보충한 경우 보충 범위와 출처를 명시한다. 확인한 판본·페이지까지만 적는다.
