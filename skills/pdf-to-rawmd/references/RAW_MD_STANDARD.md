# RAW MD 형식

PDF 페이지와 PPTX 슬라이드를 모두 페이지로 부른다. 원본의 문구·순서·계층·강조와 판독 가능한 내용을 빠짐없이 보존한다. 원문에 없는 제목·요약·해석·의학적 교정·생략 표기를 추가하지 않는다. `즉`, `등`, `…` 등이 원문에 있으면 그대로 둔다. 읽을 수 없는 부분은 해당 위치에 `[불명확: 판독할 수 없는 범위]`로 표시한다.

## 저장 구조

출력 상위 폴더(예: `01. RAW`) 아래에 입력 강의록마다 새 폴더를 만든다. 폴더명과 MD 파일명에는 확장자를 뺀 원본 파일명을 사용한다. 이미지 폴더는 강의록 사이에 공유하지 않는다. 이미지가 없는 강의록도 빈 `동봉 이미지/`를 만든다.

```text
01. RAW/
└── 1111_면역검사_박유미/
    ├── 1111_면역검사_박유미_rawmd.md
    └── 동봉 이미지/
```

같은 이름의 강의 폴더가 있으면 새 폴더명에 `_2`, `_3`을 붙이고, 내부 MD의 원본 파일명은 유지한다. 기존 자료는 이동하지 않는다. 임베드는 강의 폴더 안에서 `![[동봉 이미지/{파일명}.png|600]]`로 참조한다.

## 파일 헤더

Main은 문서 맨 앞에 한 번 넣는다. `N`은 포함한 페이지 수, `M`은 결합한 작업 파일 수다.

```markdown
# [강의명 / 파일명] — RAW MD
> 변환 일시: YYYY-MM-DD
> 원본 파일: [파일명.pdf 또는 파일명.pptx]
> 총 페이지: N
> 변환 방식: Subagent 분할 — M Chunk

---
```

## 페이지와 본문

- 각 페이지는 `<!-- page N -->`로 시작한다. 원본 번호와 순서를 유지하고 빈 페이지에도 마커를 넣는다. 빈 페이지 본문은 `*(빈 페이지)*`다. 숨김 슬라이드도 원래 순서에 포함한다.
- 페이지 블록은 제목, 본문, 표, 수식, Figure 순으로 둔다. 원본에 있는 항목만 넣고 항목 안에서는 원본 순서와 계층을 보존한다. 본문 중간에 들어 있는 인라인 수식은 원래 위치에 둔다.
- 슬라이드 제목과 교과서 섹션은 `## 제목`, 하위 섹션은 `### 소제목`을 쓴다. 글머리·번호·들여쓰기·단락·원문의 유의미한 줄바꿈을 유지한다. 굵게와 기울임은 `**굵게**`와 `*기울임*`을 쓴다. 괄호, 주석, 철자, 기호, 위첨자와 아래첨자를 보존한다. 교과서 참고 상자는 `> **[참고]** …`로 옮긴다.
- 표는 Markdown 표로 만들고 헤더와 모든 행·열·빈 셀을 보존한다. 병합 셀의 내용을 해당 셀들에 풀어 적고 표 끝에 `<!-- 병합: ... -->`로 병합 범위를 적는다. 셀 안 줄바꿈은 `<br>`를 쓴다. 셀 안 세로줄은 Markdown 표 문법에 맞게 이스케이프한다.
- 수식은 인라인 `$E = mc^2$` 또는 독립 블록 `$$\frac{d[S]}{dt} = -k[S]$$`로 전사한다. 전사할 수 없으면 `[수식: (원본 모양 최대한 서술)]`을 쓰고 판독이 불확실한 범위를 표시한다.

## Figure와 실제 이미지

학습에 필요한 그림·도식·그래프·사진마다 원본에 표시된 캡션을 그대로 옮긴다. Figure의 `N`은 원본 페이지 번호로 두고, 한 페이지에 그림이 여럿이면 `6a`, `6b`처럼 구별한다. 원본 캡션이 없으면 `[Figure N]`을 쓴다. 보이는 구조를 객관적으로 적고 모든 텍스트 레이블, 연결선, 부호, 수치와 단위를 보존한다. 학습에 필요한 색·표지·강조를 적는다. 판독할 수 없는 부분은 해당 항목에 표시한다. 세 항목 이름은 아래와 같이 쓰며, 해당 정보가 없는 항목은 `- 없음`으로 채운다.

```markdown
> **[Figure N / 그림 제목]**
> [이미지 구조 한 줄 개관]
>
> **구성 요소:**
> - [요소]: [위치, 레이블 텍스트, 형태]
>
> **흐름/관계:**
> - [화살표·연결선의 출발→도착, 방향, 부호]
>
> **범례/수치:**
> - [범례, 축 레이블, 단위, 눈금, 숫자]

![[동봉 이미지/{slug}_p{NNN}a.png|600]]
```

- Figure 바로 아래의 blockquote 밖에 실제 PNG를 임베드한다. `NNN`에는 원본 페이지 번호를 세 자리 이상으로 넣고, 같은 페이지의 그림을 `a`, `b`, …로 구별한다. 페이지 전체가 그림일 때만 `{slug}_p{NNN}_full.png`를 쓴다.
- 원본에 표시된 사진이나 렌더 크롭에 레이블·화살표·범례를 함께 담는다. 원본에 있는 별도 본문과 표 셀은 텍스트로 옮긴다. Figure의 복원이 불가능하면 묘사와 한계를 남기고 해당 페이지를 미해결로 보고한다. 파일이 없는 임베드는 넣지 않는다.

## 작업 파일

`chunk_{NN}.md`의 `NN`에는 두 자리 이상 작업 번호를 쓴다. 파일은 UTF-8로 저장하고 페이지 마커로 시작해 개행 하나로 끝낸다. 파일 헤더는 결합할 때만 넣는다. 작업 파일마다 담당 페이지 전체를 담고 페이지를 나누거나 겹쳐 쓰지 않는다.
