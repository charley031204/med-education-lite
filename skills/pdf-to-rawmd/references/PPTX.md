# PPTX 직접 처리

- `.pptx`는 프레젠테이션의 관계에 기록된 순서로 읽는다. 숨김 슬라이드도 그 위치에서 번호를 차지한다. `.ppt`는 원본을 보존하고 별도의 PPTX 또는 PDF 사본으로 변환한다.
- 담당 범위의 초안과 텍스트·서식 검토 자료를 먼저 읽는다. 화면의 제목·열·그룹·위치를 기준으로 읽기 순서를 판단한다. 그룹의 자식 좌표는 그룹 내부 좌표일 수 있다.
- 글머리, 자동 번호, 상속된 서식과 마스터에 표시되는 학습 내용을 원본 화면과 대조한다. 위첨자·아래첨자·기울임·굵게, 표 병합과 줄바꿈을 확인한다. 필요한 경우 담당 슬라이드의 OOXML에서 해당 부분만 확인한다.
- `figures INPUT.pptx --pages 1-15 --out-dir JOB/candidates`는 그림 원본을 `page_NNN_a.png` 같은 후보 파일로 저장한다. 후보는 크롭·회전·뒤집기·투명 효과·중첩을 반영하기 전일 수 있다. 단독 그림이 원본 화면과 일치하면 PNG로 저장한다. SmartArt·차트·합성 그림은 표시 상태에서 레이블·화살표·범례를 포함해 크롭한다. 차트 수치와 그림 관계는 판독 근거가 있을 때만 적는다.
- 발표자 노트를 요청받으면 별도 부록이나 파일에 보존한다. 기본 RAW MD에는 보이는 슬라이드 내용이 들어간다. 숨겨진 대체 객체의 텍스트가 화면에 보이는 내용과 중복되는지 확인한다.
- 필요한 슬라이드만 PowerPoint에서 읽기 전용·창 없이 PNG로 내보내거나 사용 가능한 PPTX 렌더러를 사용한다. 별도 PDF 사본으로 렌더할 때는 숨김 슬라이드 포함과 원본 번호 대응을 확인한다. 누락된 숨김 슬라이드나 글꼴 대체 등으로 확인할 수 없는 부분은 페이지와 함께 보고한다. 영상·애니메이션의 동작은 정지 화면으로 확인할 수 없다.

Windows에서 PowerPoint의 창 없는 렌더를 사용할 수 있으면 다음 명령으로 새 폴더에 `slide_NNN.png`를 저장한다.

```text
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/render_slides.ps1 -InputPath INPUT.pptx -OutputDir JOB/render -Slides '6,14,15'
```
